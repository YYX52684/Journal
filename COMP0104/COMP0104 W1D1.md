3. Change Integration
	- Two-Way Integration：
		Determines the difference between the two new files
		The user decides interactively what  (and from which version)  should be present
	- Three-Way Integration：
		Considers the original version.
		Non-overlapping changes can usually be merged automatically.
		Identical changes are retained once.
		Conflicting changes require a resolution.
