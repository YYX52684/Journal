## More Redirection and pipes

unix/posix commandline supports three input/output buffers called stdin, stdout and stderr.

stdout redirect:

``` bash
echo "hello" > hi.txt
```

beware that > overwrites, without warning
``` bash
echo "hello there people" > hi.txt
```

``` bash
wc hi.text
```

``` bash
wc -l hi.text
```

pipes, send stdout of one command to stdin of another

``` bash
grep "there" hi.txt 
```
``` bash
grep "there" hi.txt | wc -l
```


``` bash
grep "france" hi.txt | wc -l
```

This is the start of composing commands. This is the power of a shell program like bash

#/usr/bin/bash
for COUNT in 1 2 3 4 5
do
    echo "Creating $COUNT"
    echo $COUNT > file_$COUNT.txt
    value=`cat file_$COUNT.txt`
    value=$(($value * 5))
    echo "$value"
done
