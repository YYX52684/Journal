# Open the terminal app of your choosing

## Making a public-private key 

By convention unix machines keep their cryptographic key material in the hidden `.ssh/` directory

``` bash
cd ~/.ssh
ssh-keygen
```

You may need to create .ssh if it doesn't already exist. 

Give it a name, I used "condenser". For the sake of being slack I did not use a passphrase for now.

## Upload the PUBLIC key

Use the Burger to open the left hand menus then

1. Virtualisation Management -> select the cluster "sl-p01"
2. Left hand menu -> Advanced -> ssh keys -> create

Give you key a handy name (your name or UCL username), then get the contents of your ssh.pub and paste it here 

ID-comp0235-ns


## Sign your key!

Head to https://vault.arc.ucl.ac.uk/ui/

we are oidc with 'default' Role. Then signs in with UCL SSO (if it's not already in your cookies)

Left hand menu -> Secrets Engine -> ssh-environments-ingress -> cloud-user

Add your public key text, without anything after the space, and Click Sign

Copy the signed key that comes back, you only get to see this once, but you can sign again as often as you want.

If you don't see "ssh-environments-ingress" in the vault system you can also sign your key via 

https://ssh.condenser.arc.ucl.ac.uk/

Click the link to upload a key (if there is already a key you can delete it, and re-add your key). Then follow the link to generate a 
certificate. If you already have a certificate you can click the revoke button and then choose the generate option.

## Save the signed key material

``` bash
touch ~/.ssh/condenser_vault_signed_key.txt
```

The paste the contents of the key in to this file and save

## Configure SSH to make life a little easier

If you don't have an ssh config then make one!

``` bash
touch   ~/.ssh/config
```

``` txt
Host condenser
  HostName ssh.condenser.arc.ucl.ac.uk
  User cloud-user
  CertificateFile ~/.ssh/condenser_vault_signed_key.txt
  IdentityFile ~/.ssh/condenser
```

## Now test our credentials

Then you can ssh 

``` bash
ssh condenser
```

Should authenticate and then immediately close the connection with not error if authentication works

## Lets build a machine and attach to it

Head to https://rancher.condenser.arc.ucl.ac.uk/

1. Virtualisation Management -> select the cluster "sl-p01" -> "Virtual Machines" -> 'Create"

2. Fill in name and descprition. 4 CPUS and 4GiB, and set you ssh key
3. Image: latest AlmaLinux and 40GiB disk space is fine
4. Network: ds4eng-ns/ds4eng
5. Configure for external HHTP access

condenser.ingress/isEnabled = true
condenser.ingress/isAllowed = true
condenser.ingress.hosttest/hostname = hosttest

Once it is up and running copy the IP address for this machine. This IP is only available WITHIN UCL

## Connect

Now connect to the IP of the machine as 
ssh -i ~/.ssh/condenser -J condenser almalinux@10.134.10.3
