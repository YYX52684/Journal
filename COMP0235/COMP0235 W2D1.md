# Writing a hosts file

``` bash
mkdir ansible_test
cd ansible_test
touch hosts
```

```
[myhosts]
IP OF CLIENT MACHINE
```


``` bash
ansible all -i hosts --list-hosts
```
see the hosts. note we're providing and explicity hosts file here


replace 'ansible_key' with the name of your private identity
``` bash
ansible all -i hosts -m ping --key-file ~/.ssh/ansible_key
```

# Inventories

``` bash
touch inventory.yaml
vi inventory.yaml
```

An inventory of all our controllable hardware

```
mymachines:
  hosts:
    machine01:
      ansible_host:  IF OF CLIENT MACHINE
```

``` bash
ansible-inventory -i inventory.yaml --list
```

replace 'comp0235' with the name of your private identity
``` bash
ansible mymachines -m ping -i inventory.yaml --key-file ~/.ssh/comp0235
```

# Simple Playbook

``` bash
touch playbook.yaml
vi playbook.yaml
```

We're going to do two tasks
```
- name: My first playbook
  hosts: mymachines
  tasks:
   - name: Ping my hosts
     ansible.builtin.ping:
   - name: Print message
     ansible.builtin.debug:
       msg: Hello world
```

``` bash
ansible-playbook -i inventory.yaml playbook.yaml --key-file ~/.ssh/ansible_key
```
